# OrganoSilvia

Premium Next.js landing page for OrganoSilvia, a skincare brand focused on daily natural skincare for Indian skin.

## Stack

- Next.js 16 App Router
- TypeScript
- Tailwind CSS 4
- Framer Motion
- Lucide React

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Included sections

- Sticky header with mobile navigation
- Hero with trust badges and premium product visual
- Product showcase
- Problem / solution section
- Ingredient story grid
- Daily routine timeline
- Testimonials
- Why choose OrganoSilvia
- SEO blog preview cards
- FAQ accordion
- Final marketplace CTA

## Notes

- Marketplace links currently point to placeholder Amazon and Flipkart URLs.
- Product visuals are SVG placeholders in `public/products/` and can be replaced later with real assets.
